OPTION 1: INSTANT START (Easiest!)
───────────────────────────────────
1. Simply double-click the "index.html" file
2. Your website opens in your default browser
3. That's it! ✅

OPTION 2: LOCAL SERVER (Recommended for Development)
──────────────────────────────────────────────────────
Windows:
1. Open Command Prompt (Windows + R, type 'cmd')
2. Type: cd path\to\Doxinova
3. Type: python -m http.server 8000
4. Open browser: http://localhost:8000

Mac/Linux:
1. Open Terminal
2. Type: cd path/to/Doxinova
3. Type: python3 -m http.server 8000
4. Open browser: http://localhost:8000

================================================================================
                          🆘 TROUBLESHOOTING
================================================================================

Page not loading?
  → Make sure all files are in the same folder
  → Try using a local server (see OPTION 2 above)

Styles not showing?
  → Press Ctrl+Shift+R to clear browser cache
  → Check that styles.css is in same directory

Contact form not working?
  → Make sure your email client is configured
  → Or edit script.js to use a backend service

Mobile menu not working?
  → Try different browser
  → Clear browser cache
  → Check JavaScript console (F12)

👉 See INSTALLATION.md for more troubleshooting
