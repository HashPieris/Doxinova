# DOXINOVA Website

## Doxycycline-Citronellol Nanoemulsion Research Portfolio

Website profesional untuk tim penelitian DOXINOVA dari Universitas Palangka Raya.

---

## 📋 Project Overview

**DOXINOVA** adalah penelitian inovatif yang mengembangkan nanoemulsi doxycycline berbasis citronellol oil sebagai sistem penghantaran obat untuk meningkatkan efektivitas terapi kanker ovarium.

### Research Details
- **Institusi:** Universitas Palangka Raya, Kalimantan Tengah, Indonesia
- **Program:** Kedokteran Program Sarjana
- **Durasi:** 4 bulan
- **Budget:** Rp 9.351.000,00
- **Fokus:** Pengembangan nanomedisin dengan pendekatan in silico dan in vitro

## 🔧 Installation & Setup

### Method 1: Direct Opening
1. Open `index.html` in your web browser
2. No installation required - pure HTML/CSS/JavaScript

### Method 2: Local Server (Recommended)
```bash
# Using Python 3
python -m http.server 8000

# Using Python 2
python -m SimpleHTTPServer 8000

# Using Node.js (if installed)
npx http-server
```
Then visit: `http://localhost:8000`

## 📧 Contact Integration

The contact form uses mailto integration:
- Opens default email client
- Pre-fills recipient email
- Includes form data in email body
- No backend required

To change recipient email, edit in `script.js`:
```javascript
const mailtoLink = `mailto:your-email@example.com?...`
```

## 🎨 Customization Guide

### Change Colors
Edit CSS variables in `styles.css`:
```css
:root {
    --butter: #E8D5B7;
    --cherry: #8B3A3A;
    --olive: #6B8E23;
    --oat: #C5B8A8;
}
```

### Add New Sections
1. Add section in HTML with unique `id`
2. Add corresponding CSS styles
3. Update navigation menu to include new link

### Modify Content
- Edit text directly in `index.html`
- Update team member information
- Change project details
- Add new features or accomplishments

### SVG Illustrations
- All SVG code is inline in HTML
- Edit SVG attributes for customization
- Can add external SVG files in `assets/vectors/`
